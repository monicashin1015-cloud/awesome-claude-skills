# Krosiny Niche Design Scout

원본: [ComposioHQ/awesome-claude-skills — competitive-ads-extractor](https://github.com/ComposioHQ/awesome-claude-skills/tree/main/competitive-ads-extractor)를
`workspace-kr-monica`에 맞게 고쳤다 (2026-10-01, 10/1주 전체회의 "오픈소스 레포 포크" 액션 아이템 + "POD 디자인 변형 리서치").

## 원본과 다른 점 — 왜 이렇게 바꿨나

1. **대상을 Facebook/LinkedIn 광고 라이브러리에서 아마존·Etsy 리스팅으로 바꿨다.** 우리가 파는 건 광고 카피가 아니라 **디자인 자체**(향초 문구, 화분 패턴)라서, 원본이 보는 "메시지·CTA"보다 "무슨 그림·문구가 어느 니치에서 먹히는지"가 필요하다.
2. **자동 스크래핑을 쓰지 않는다.** 원본은 "Scrapes ads from Facebook Ad Library"라고 되어 있는데, 아마존은 자동 수집이 이용약관 위반 소지가 있다(CLAUDE.md 보안 원칙과 같은 결). 대신:
   - 아마존 경쟁 리스팅 조사는 이미 연결된 **Helium 10 MCP**(`search_competitors_by_asin`·`get_market_products`·`search_niche_by_keyword`)를 쓴다 — 이미 승인된 정식 API다.
   - Etsy·핀터레스트 등 아마존 밖 자료는 **Claude in Chrome으로 사람이 보듯 하나씩** 열람·스크린샷한다. 대량 자동 수집 스크립트를 새로 만들지 않는다.
3. **"베끼지 않는다"를 더 강하게 못박는다.** 원본 Step "Don't copy ads directly"는 광고 문구 기준인데, 디자인은 표절 위험이 카피 문구보다 크다(도안 자체가 저작권·상표권 대상). 그래서:
   - 뽑아내는 건 **패턴**(예: "낚시대 실루엣 + 캘리그라피 문구 조합", "피클볼 라켓 + 유머러스한 문구")이지 **원본 이미지 합성/트레이싱이 아니다.**
   - 결과물에 "이 패턴을 참고해 새로 그린다" 단계를 반드시 넣고, 발견한 원본 이미지를 그대로 우리 리스팅에 쓰자고 제안하지 않는다.
   - 후보가 나오면 **상표권 확인은 `/trademark-check`로 넘긴다** — 이 스킬은 리서치까지만, 등록 여부 확인은 별도.

## 언제 쓰나

- 금요일 제출용 "베스트셀러 디자인 → 우리 니치 변형" 리서치 (10/1주 회의 액션 아이템, 기한 2026-10-02)
- 향초·화분 신상 디자인 후보를 정할 때 "지금 이 니치에서 뭐가 팔리는지" 먼저 훑어볼 때
- 열린 일 표의 "POD 디자인 변형 리서치" 항목(유튜브 영상 대조만으로 막혀 있던 것) 재료 보강

## 어떻게 하나

1. **니치 확정** — 어느 틈새(피싱·피클볼·골프 등)를 볼지 먼저 확인한다. 한 번에 1~2개로 좁힌다(넓히면 결과가 흐려진다).
2. **아마존 쪽 — Helium 10 MCP로 조회**:
   - `search_niche_by_keyword`로 그 니치의 향초/화분 키워드 검색량·경쟁 파악
   - `search_competitors_by_asin` 또는 `get_market_products`로 상위 리스팅의 디자인 이미지·타이틀·리뷰수 확인
   - 리뷰에서 "이 문구가 좋았다"·"선물용으로 샀다" 같은 실제 구매 이유 코멘트를 같이 본다(있으면) — 디자인만 보고 짐작하지 않는다
3. **Etsy·핀터레스트 쪽 — Claude in Chrome으로 직접 열람**:
   - 검색 후 상위 결과 몇 개만 스크린샷(대량 저장 안 함)
   - 판매량·리뷰수가 보이면 같이 기록(짐작 금지 — CLAUDE.md 제1원칙)
4. **패턴으로 정리** — 이미지가 아니라 아래처럼 말로 뽑는다:
   ```markdown
   ## 피클볼 니치 — 관찰된 패턴
   - 구도: 라켓+공 실루엣을 중앙에, 문구는 위/아래 곡선 배치
   - 문구 톤: "PICKLEBALL IS MY THERAPY" 류 유머러스한 1행 문구가 반복됨(상위 5개 중 4개)
   - 색상: 형광 옐로+네이비 조합이 많음
   - 근거: [Helium10 검색 2026-10-01, ASIN B0XXXXX 외 4건] / [Etsy 검색 스크린샷 2026-10-01]
   ```
5. **우리 제품으로 변형 아이디어 1~2개 제안** — 패턴을 우리 향초/화분 SKU 형태에 맞게 바꿔본다. "그대로 따라 그리기"가 아니라 "이 구도·톤을 우리 브랜드 톤으로 재해석"임을 명시.
6. **다음 단계 안내** — 후보가 정해지면 `/trademark-check`로 상표권 확인, `/design-screen`으로 기존 디자인과 중복 여부 확인.

## 출력 형식

```markdown
# 니치 디자인 리서치 — 피클볼 (2026-10-01)

## 관찰
[패턴 3~5개, 근거 병기]

## 변형 아이디어
1. [아이디어] — 참고 패턴: [패턴 이름] / 원본 그대로 아님, 우리 톤으로 재해석
2. ...

## 다음 확인
- 상표권: /trademark-check 로 후보 N개 확인 필요
- 기존 디자인 중복 여부: /design-screen
```

## 하지 않는 것

- 아마존 리스팅을 자동 스크래핑하지 않는다 (Helium 10 MCP 정식 경로만 사용)
- 경쟁사 이미지를 그대로 합성·트레이싱해서 결과물에 넣지 않는다
- 상표권 판단을 이 스킬 안에서 내리지 않는다 (`/trademark-check` 몫)
- 노션에 자동으로 올리지 않는다 — 리서치 결과를 Monica가 검토한 뒤, 금요일 제출용 노션 페이지는 별도로 만든다

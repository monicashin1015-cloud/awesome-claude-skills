# Krosiny Changelog

원본: [ComposioHQ/awesome-claude-skills — changelog-generator](https://github.com/ComposioHQ/awesome-claude-skills/tree/main/changelog-generator)를
`workspace-kr-monica` 저장소에 맞게 고쳤다 (2026-10-01, 10/1주 전체회의 "오픈소스 레포 포크" 액션 아이템).

원본과 다른 점:
- 독자가 "고객"이 아니라 **대표님·팀원**이다 — "출시했습니다" 톤이 아니라 "뭐가 왜 바뀌었는지"를 설명한다.
- 이 저장소는 **하루 20커밋이 정상**이고 대부분이 `auto-sync:` 자동 저장·병렬 세션 커밋이다(CLAUDE.md "git — 이 저장소는 여러 세션이 동시에 쓴다"). 원본 스킬은 이 필터가 없어서 그대로 쓰면 노이즈투성이가 된다.
- `/weekly-report`·`/krosiny-bugfixes`가 이미 "주간 요약"·"버그만 추린 공유"를 하고 있으므로, 이 스킬은 그 사이 빈틈 — **주간 주기 밖에서 "지금까지 뭐가 바뀌었나" 즉석 조회**를 채운다. 정기 자동 실행이 아니라 필요할 때만 부른다.

## 언제 쓰나

- 대표님이 "그동안 뭐 고쳤어?"라고 물었을 때 (금요일 정기 보고 전이라도)
- 특정 기능(예: 재발주 룰, 자금 대시보드)만 골라 "이번 달 이 부분 뭐 바뀌었나" 볼 때
- PR 머지 여러 개가 쌓였을 때 한 번에 정리

## 어떻게 하나

1. **범위 확인**: 기간(예: "지난 7일") 또는 파일/폴더(예: "make_po_budget.py만") 중 뭘 볼지 먼저 확인한다.
2. **커밋 수집**: `git log --since=<날짜> --pretty=format:'%h|%ad|%an|%s' --date=short -- <경로>`
3. **노이즈 제거** — 아래는 기본적으로 뺀다 (CLAUDE.md 병행 세션 규칙과 동일 기준):
   - `auto-sync:` 로 시작하는 커밋 (5분 자동 저장)
   - `Merge branch` 커밋
   - 순수 서식·오타 정정 커밋(제목에 "정정"만 있고 동작 변경 없음 — 커밋 본문에서 확인)
4. **분류** — 이 저장소 맥락에 맞는 카테고리로 묶는다:
   - 🧮 **계산 로직** (발주 수량·자금·MOQ·재발주 판정 — 틀리면 돈·물량이 잘못 나가는 것)
   - 🐛 **버그 수정**
   - ✨ **새 스킬·자동화**
   - 📋 **룰 변경** (`memory/*.md` 룰 원전이 바뀐 것 — CLAUDE.md "비즈니스 룰은 코드 전에 memory 먼저" 대상)
   - 🧹 **정리·리팩토링** (기본적으로 목록엔 넣되, "왜 안 급한지" 알 수 있게 맨 아래로)
5. **한국어 업무 언어로 번역** — 기술 용어·함수명 나열 금지 (CLAUDE.md "계획 설명 시 업무 언어로 번역" 규칙과 동일). 예: `calc_costs() 에서 round 자리 수정` → "발주 비용 계산에서 반올림 자리가 하나 어긋나 있던 것을 고쳤다 (실제 금액 차이는 몇 센트 수준)".
6. **출처를 남긴다** — 각 항목 옆에 커밋 SHA 짧은 형태(`617ace3a`)를 붙여, 나중에 "이거 어디서 나온 얘기야?"를 커밋 하나로 추적할 수 있게 한다 (CLAUDE.md 제1원칙 "산출물은 확인 가능한 FACT만").

## 출력 형식

```markdown
# 최근 변경 요약 — 2026-09-22 ~ 2026-09-28

## 🧮 계산 로직
- 발주 비용 계산에서 젓가락 제품비가 쌍수 대신 세트수로 잘못 나뉘던 것을 고쳤다 (795c0ca7)
- 자체 시험(selftest)에 "손으로 계산한 절대 금액"을 추가해, 곱셈·나눗셈이 바뀌어도 통과하던 구멍을 막았다 (617ace3a)

## 🐛 버그 수정
- ...

## ✨ 새 스킬·자동화
- ...

## 📋 룰 변경
- ...
```

## 하지 않는 것

- 새 자동화로 등록하지 않는다 — 부를 때만 도는 즉석 조회 도구다. CLAUDE.md "새 자동화 도입 전 그릴링" 대상이 아니다(자동 실행 안 함).
- 노션에 쓰지 않는다 — 채팅 답변으로 끝낸다. 정기 기록이 필요하면 `/weekly-report`·`/worklog-sync`를 쓴다.
- 회사 저장소(TM-Krosiny-OS)에 그대로 올리지 않는다 — 필요하면 `/krosiny-bugfixes`(코드 버그만) 또는 `employee-pr-workflow`를 따로 쓴다.
